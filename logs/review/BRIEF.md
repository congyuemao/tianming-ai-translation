# 三道独立复核说明

书：Nigel Harris《天命：马克思与毛泽东在现代中国》中译本。仓库 `C:\Dev\tianming-ai-translation`，分支 `claude-polish`。全书刚由多个子代理对照英文重新润色过（方针见 `logs/decisions.md`、`logs/polish/BRIEF.md`）。润色改得越多，越容易改出新错，所以请你做独立复核。你没有参与润色，不要预设润色是对的。

- 英文底本：`source/en/<章名>.md`（`<!--p.N-->` 为原书页码，注释在章末）。
- 译稿：`each_chapter/<章名>.md`。润色前的版本：`git show main:each_chapter/<章名>.md`。
- 本章润色日志：`logs/polish/<前缀>.md`；待定问题汇总：`logs/polish/OPEN.md`。

## 共同规则
- **确定是错的，直接改**；拿不准的不改，写进报告。改动要小而准，不要借机重新润色整段。
- 不改：事实、立场、语气强度；已恢复中文原文的引文（台账 restored，`tools/polish_guard.py` 检查）；用户已认可的成语和讽刺意译（除非意思错了）。带“译注：此句为意译”的句子是有意意译，只查意思有没有偏。
- 段落数不能变，注号不能乱。需要加注用 `python -I tools/add_note.py <前缀> "<紧挨注号前的唯一文字>" <注文文件>`（注文文件放 `C:\Users\21161\AppData\Local\Temp\claude\` 下自己的子目录）。
- 改完运行 `python -I tools/polish_guard.py --chapter <前缀> --renumbered <前缀>`，必须零错误。
- 每处改动记进日志 `logs/review/<道次>/<前缀>.md`，一行一条：页码或注号｜原文｜改前｜改后｜理由。
- 不要 git commit，不要碰别的章节。
- 最后回复只写：每章改了几处（按类别计数）、polish_guard 结果、拿不准请主控定的条目（一行一条）。

## 第一道：润色后对原文复核（日志目录 `logs/review/1/`）
逐段对照英文看润色稿，专找**改偏**的地方：
- 限定词丢了或变了（one of、some、presumably、it seems、apparently、perhaps、largely）；
- 语气被加重或减弱，作者没有的判断被加进去（“显然”“不得不承认”“所谓”“照此看来”）；
- 信息漏了（一个数字、一个例子、一个分句、括号里的话）或多了；
- 指代不清、主语换了、因果或时间先后颠倒；
- 成语俗语用错了意思或褒贬（对照 `logs/成语俗语对照表.md` 的语境义），一句堆两个成语，同章重复；
- 讽刺意译把讽刺对象或力度弄偏了。
也看注释：校注是否准确、是否还有“本轮”“到件”“用户提供”之类流程用语。

## 第二道：终审，专查实质译错（日志目录 `logs/review/2/`）
不管文笔，只看意思是否正确：
- 倍数和增减（“增长了3倍”与“增长到3倍”）、百分比、数字、年代、日期与原书一致（原书的事实错误应照原书译并有校注；译稿悄悄改正的要恢复并加校注）；
- 否定范围、并列与条件、让步与转折；
- 书名、刊名、专名、人名、地名、机构名译对了没有，全章一致；
- **引文核查**：引号里标为毛泽东、马克思、恩格斯、列宁、斯大林、周恩来、党和政府文件、中文报刊原话的中文，凡**不在台账里**（台账：`reference check/2026-10-16-round45.json` 的 records）的，到中文马克思主义文库（https://www.marxists.org/chinese/ ，毛泽东文集、马恩全集、列宁全集等）或其他可靠来源核对。核到原话的，按原话校正并在注里写明出处（如“中文据《毛泽东选集》第二卷《……》”或网页录文链接）；核不到的，引文改为按原书英文忠实译出，不得保留凭记忆写的“中文原话”，必要时注明“据英文译出”。每条引文最多查 3—5 次，查不到就停。`logs/polish/OPEN.md` 里点名的未核引文和凭记忆写的史实校注，优先核。

## 第三道：通读校对（日志目录 `logs/review/3/`）
只读中文，像出版社校对一样一字一句读完，注释也读。不润色，不改写，只找：
- 错别字、漏字多字、读不通的句子；
- 半角标点混入（中文正文里的 , . : ; ( ) " ），引号、括号、书名号不成对；
- 同一专名前后写法不一；
- 注号与注释对不上（正文 [n] 与章末第 n 条），注释离开正文读不懂；
- 年份、数字前后矛盾；格式约定（`logs/decisions.md`）没执行的地方，如数字与汉字间多空格、“1960年代”写法、〔n〕注号残留。
引文里的旧式用字不改。
