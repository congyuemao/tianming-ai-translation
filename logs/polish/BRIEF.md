## 读者与力度
面向想认真了解这段历史的普通中文读者。去翻译腔：读一句，如果能一眼还原出英文语法结构，就重写。拆长从句，先背景后动作、先原因后结果；名词化还原成动词；删多余的“一种”“这一”“进行”“被”；抽象名词作主语改成人作主语；一句超过三个“的”就拆。也别走到另一头满篇短句，长短相间。学术性的定义和推理处概念要准。

不能动的：事实、数字、日期、立场、语气强度、限定词（one of the first 不能成“最早”，presumably 不能成“显然”，it seems 不能成断言）。**不加作者没有的判断，不加防御性说法，不加提示语**（“照此看来”“所谓”“值得注意的是”，原文没有就不加）。不删任何信息，不写“此处略”。

## 成语俗语
- 用户已认可《成语俗语对照表》，**照表执行**：在对应位置用 `suggest`；句子重写后 `suggest` 放不进去时可以用 `alt` 里的备选，或按 note 的意思写平实译法。
- 表外不随意加成语。表外偶尔需要一个现成说法才通顺的，可以用，但记进日志。
- 同一章同一说法不超过一次；一句不堆两个成语；不写文言腔。

## 讽刺反话
- 用户已认可《讽刺反话对照表》的意译建议，**默认采用 `suggest` 第一条**（可微调以贴合改写后的句子）。
- 例外：该条 `risk` 本身说“正文用直译即可”“直译已能传达”“用力过猛”之类、倾向直译的，用 `literal_zh`。
- 采用意译时，如果意译**加进了原文没有的字眼、意象或政治说法**（如“思想觉悟”“尝不出味道”“成绩斐然”加引号），就用下面的脚本加一条译注：`译注：此句为意译。原文直译为：“……”。`（引号里放 `literal_zh`，内部引号改用‘’）。只是把同一意思说得更地道、没有添加东西的，不加译注。
- 讽刺靠措辞本身，不加“照这个说法”之类原文没有的提示语。

## 引文
- **已恢复中文原文的引文**（台账 status=restored，引号里是查到的中文原话）：引号内一字不改。`tools/polish_guard.py` 会检查。
- **“部分核实”的条目**（`partial_items.json`）：英文转引来源已核到，中文原话没找到。按英文忠实译出，**撤去【原文待核】**。本句已有注释的，在该注里写明“据某某（刊物、页码）英文转引译出，中文原话未见”，并保留 researchNote 里说到的出入；没有注释可依附、但有需要交代的出入的，用脚本加一条校注；只是短语、没有出入可说的，不必加注。
- **其余【原文待核】**（已检索未落实）：保留标记，引文措辞可以按英文改得更准、更顺。

## 注释
- 书目信息（书名、篇名、刊名、作者、出版地、日期、页码、URL）保留英文原样；说明性文字用中文。
- “校注”改写成写给读者看的话：讲清来源、出入、是否据英文译出。删去“本轮”“到件”“用户提供”“续查”“台账”“不再列为未到件”“第N轮”之类工作流程用语。来源链接（`../reference%20check/sources/...` 和网页链接）保留。
- 正文里夹着的〔校注：……〕、【核校提示】等，移入章末注释（用脚本插注，注号自动顺延）。
- 原书的事实错误（日期、人名、地名）：**正文照原书译，加校注说明史实**。现译稿悄悄改正、没有加注的，恢复原书写法并加校注。不确定的不改，记进日志。

## 格式（全章统一）
- 正文注号统一写 `[n]`（现稿有的用〔n〕）。注号放在标点之后，与现稿一致。
- 数字与汉字之间不加空格（“1966 年”→“1966年”）。
- 年代写“20世纪60年代”。统计、计量数字用阿拉伯数字（240万、17.5公里）；引文里的中文原话不动；约数和习惯说法用汉字（十七年、三四个）。
- 人名、地名、机构名沿用现稿已有译法，除非明显错误（改了记进日志）。全书已通行的写法：毛、周恩来、刘少奇、国民党、共产国际、中华全国总工会等。
- 中文标点全角，引号“”‘’，书名号《》，破折号——，省略号……。

## 工具
- 插注（自动顺延后面的注号，正文注号统一成 [n]）：
  ```
  python -I tools/add_note.py <章节前缀> "<正文中紧挨注号前、全章唯一的一段文字>" <注文文件>
  ```
  注文先写进一个临时文件（放 `C:\Users\21161\AppData\Local\Temp\claude\` 下你自己的子目录），不要写进仓库。插注要在你把整章写好之后再做，一条一条插。
- 校验（必须零错误）：
  ```
  python -I tools/polish_guard.py --chapter <章节前缀> [--renumbered <章节前缀>] --verbose
  ```
  加了注就带 `--renumbered`。段落数必须不变（空行分段；不要合并或拆分段落，标题行保持标题）。每条警告都要看：数字变化应当只是格式转换（汉字数字改阿拉伯数字、年代写法）或你在日志里写明的改正；待核数变化应当正好对应你处理的部分核实条目。
- 写文件用 UTF-8、LF 换行。可以整章用 Write 写，也可以分段 Edit；写完通读一遍。
