# 谭震林1966年9月7日讲话目标段

来源：[《谭震林在文革初期的十三次讲话》](https://speechfree.github.io/cultural-revolution-database/post/1496/)，第五项“1966.9.7 在农政，农办机关人员全体会议上的讲话”。复用第二十二轮保存的网页，本轮再次核对目标段；合辑页首1966年6月18日不是本段日期。

> 用现在这样生产方法，谁愿意在农村，都想往城里跑，在城市扫扫地，一月三四十元，农村一年也不过二三百元。在这个会上要问谁愿意当农民，叫大家举手，有举手的也是勉强。

网页注明按语为北京农业大学红卫兵所加，材料末署东方红公社、遵义部队。这里仅摘讲话对应段，未把批判按语混入引文；没有原刊影像，不能视为本人审定稿。

Deleyne第58页同时列农村年收入200—300元和月收入20元；Harris第111页只保留月收入20元。正文按此中文录文恢复年收入，保留原书节引范围，起于“都想往城里跑”，止于询问谁愿当农民，以省略号标明后续未引。原注1967年3月6日刊物及其与此录文的关系尚未核定。
