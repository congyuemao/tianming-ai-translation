# 1948年土地改革文件：干部条件摘录

来源：[毛泽东《一九四八年的土地改革工作和整党工作》](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19480525.htm)，1948年5月25日，第二节甲项第三个条件；本轮重新读取并核对。

> 第三，党的工作干部在数量上和质量上，确能掌握当地的土地改革工作，而非听任群众的自发活动。

上下文限定当年土改范围：三个条件包括消灭当地敌人武装并使环境安定、基本群众绝大多数要求分地，以及干部具备掌握工作的数量和质量；任何一个不具备，均不应列入1948年土改范围。

11-01正文引用第三项的措辞，省去列举序号。Gluckstein第93页及Harris原注仍列1950年12月10日《新观察》、CB63；尚未取得这些1950年材料，未证明其转载了1948年文件。采用这一对应中文校引，不等于核定整个转载链。
