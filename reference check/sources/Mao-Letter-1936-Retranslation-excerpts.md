# 1936年8月10日致章乃器等人信：所采中文刊本摘录

来源：[《毛泽东集补卷》第4卷](Mao-Collection-Supplement-Vol4.pdf)，苍苍社，1984年；复用此前归档PDF。本轮目视核对[第297页](Mao-Supplement-Vol4-p297.png)题名和日期、[第301页](Mao-Supplement-Vol4-p301.png)、[第302页](Mao-Supplement-Vol4-p302.png)及[第306页](Mao-Supplement-Vol4-p306.png)版本说明。下文由繁体转为简体，保留措辞；不是重新翻译英文。

第301页，03-04所用段落：

> 我们已经通过决议不没收富农的土地，如果他们愿意和我们共同抗日的话，我们并不拒绝与他们联合。不没收大小工商业者的财产与工厂，并保护他们的企业，帮助他们发展，以增加苏区抗日运动所必需的物质供给。

第301—302页，03-07所用完整句：

> 劝告工人不提出超过本企业能力的要求。在非苏维埃区域，我们主张必须改善工人生活，但希望不加深反资本主义的斗争。

正文按Harris节引范围，在改善工人生活分句处加省略号；这里保留完整句以便检查删节。第302页随后另一段的两句英文未译说明，不是上述目标句缺字。

第306页《救国时报》编者说明：所刊中文从英国方面取得的英文译稿再次译出，字句可能与中文原本不同，待取得中文原本后再发表。来源栏列《救国时报》1936年10月30日，另列《救国会》（中国社会科学出版社，1981年10月）。本轮采用汇编所收的当年再译刊本文字；没有取得信件中文原稿、该期《救国时报》或原注英文集第75—76页。
